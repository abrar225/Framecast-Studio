Open about what comes next.

Framecast Studio is an early release, and the project is developed in public. Here is the current line between available features and work still in progress.

● Available in the app

  • ✓ Screen and camera scenes, built-in layouts, and editable transforms
  • ✓ Landscape, portrait, or linked dual-canvas recording
  • ✓ Local H.264 or HEVC recording with configurable output settings
  • ✓ Microphone and captured app-audio mix with live meters
  • ✓ Private YouTube broadcast setup and local remote control

◌ Still in progress

  • ↗ Guest rooms, backstage calls, and separate guest tracks
  • ↗ Twitch, Kick, and other destination integrations
  • ↗ Multi-platform chat and multistream management
  • ↗ Notarized distribution and broad device/performance validation

The project does not claim feature parity with other studio products. See the repository's Known limits for the full list.

Good to know

Before your first session.

Practical details for anyone building or trying Framecast Studio.

An independent, MIT-licensed native macOS application for composing screen and camera scenes, recording landscape and portrait video, and testing private YouTube broadcasts.
The project targets macOS 14.2 or later. The release has been exercised on Apple Silicon; Intel support and a broad device/OS matrix have not been verified. See the repository build guide for compiler and optional FFmpeg requirements.
Not yet. The current account workflow supports private YouTube broadcasts. Twitch/Kick destinations, multistreaming, and unified multi-platform chat are not implemented.
Local recordings are written on your Mac using Apple's media frameworks. You choose where to store recordings in the app. When broadcasting, the configured stream is sent to the selected destination; review its settings before going live.
There is no published notarized installer in the repository yet. You can inspect the source and follow the build instructions. A self-built app may require you to approve macOS capture permissions, and signing changes can require approval again.
Start with the contribution guide and open a focused issue or pull request on GitHub. The code is MIT licensed; bundled components and platform tools retain their own licenses.
